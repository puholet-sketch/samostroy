# Поля карточки клиента (эталон prod CRM)

Источник: `https://crm.1-remont.com/clients?get_client=…` — **только просмотр**, 2026-10-22.  
Пример договора ремонта: `/dogovor?get_dogovor=8140` (№13352 в системе не найден / ошибка модуля).

## Список клиентов (колонки)

ФИО · Телефон · Email · Договор дизайн · Смета · Договор отделка · Город · Менеджер · Дизайнер · Комплектатор · Прораб · ОТК · # · Источник

## Редактирование клиента (`/clients?get_client=ID`)

### Основные

| Поле (UI) | name в форме |
|---|---|
| Статус: Физ / Юр лицо | `fizurlico` (`fiz` / `ur`) |
| ФИО клиента / Название организации | `name` |
| Email | `email` |
| Мобильный основной | `mobile` |
| Мобильный дополнительный | `mobile2` |
| Менеджер | `manager` |
| Дизайнер | `designer` |
| Комплектатор | `picker` |
| Прораб | `prorab` |
| ОТК | `otk` |
| Город | `city` / `city_name` |
| Тег | `tag` |
| Источник | `source` / `source_name` |
| Ссылка на AmoCRM | `amo_link` |
| Объекты клиента | (связанный список) |
| Создан | `createdAt` (сортировка реестра) |

> Убраны нерабочие галочки портала `client_access_remont` / `client_access_design` — внутренний CRM без клиентских ACL-тогглов.

### Паспорт / персональные (для договоров и актов)

| Поле | name |
|---|---|
| Дата рождения | `dob` |
| Место рождения | `pob` |
| Тип паспорта | `type_passport` |
| Номер паспорта | `passport_number` |
| Паспорт выдан | `passport_issued` |
| Дата выдачи | `passport_date_issued` |
| Адрес регистрации | `address` |
| Сканы: паспорт главная / прописка | `files_1`, `files_2` |

### Юрлицо (если ur)

`lico`, `osnovanie`, `podpisant`, `address_ur`, `inn`, `kpp`, `bank`, `bik`, `rs`, `ks`

## Договор ремонта (поля из КК + договора)

`client_fio`, `client_address`, `number`, `date`, `status`, команда (manager/designer/picker/prorab/otk), `itogo_summa`, `payment_1…4`, этапы

## Документы СамоСтрой (из рыб)

Меняется по клиенту: **ФИО**, **паспортные данные**, **перечень работ**, в расчётах — **сумма оплаты** и **остаток**.
