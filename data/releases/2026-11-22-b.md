# 2026-11-22-b — Канал, LHR, журнал ошибок

## Зачем

1. На мобиле в Клиентах фильтр «Канал продаж…» обрезался и мешал читать.
2. Форма прораба снова писала «Сохранено локально (API: Failed to fetch)» — free `*.lhr.life` ротировал hostname, а Pages ещё смотрел на мёртвый URL.
3. На телефоне сложно понять, почему упал POST: нет долгоживущего следа ошибки.

## Что сделано

- Фильтр канала: короткий ярлык «Канал» в Клиентах и на Контроле объекта.
- Публичный API: живой LHR `https://cc287da7947296.app.lhr.life` (`/health` → 200); LAN API на Lenovo был здоров, упал только туннель-hostname.
- Клиентский журнал: `samostroy:error_log` (кольцо ~40 записей) + `console.error` с url/status/route; просмотр в Настройки → API / уведомления (владелец).
- Покрыты пути: feedback API, POST/hydrate отчётов, control-link sync, CRM-seed (dev).

## Ограничения

- Free `*.lhr.life` снова сменится при рестарте `samostroy-lhr` — тогда обновить `.env.production` и Pages.
- Если в CRM сохранён старый Base URL в localStorage, он перекрывает URL из сборки — очистите override или пропишите новый hostname.
- Журнал только на этом устройстве/браузере (не серверный лог).

## Как пользоваться

1. Клиенты / Контроль: в фильтре видно «Канал», не обрезку.
2. Отчёт прораба с телефона → «Отчёт сохранён в общую базу» при живом туннеле.
3. Настройки → API / уведомления → «Журнал ошибок API» после сбоя.
