# 2026-11-22-d — Runtime API URL без полного rebuild

## Зачем

Free localhost.run периодически ротирует hostname. Раньше GitHub Pages «умирал» до ручного redeploy с новым `VITE_FEEDBACK_API_URL`. Нужна цепочка, где свежий URL попадает в CRM без сборки Vite.

## Что сделано

- При старте CRM читает `api-config.json` с Pages (no-cache); приоритет: Настройки CRM → runtime файл → bake env.
- Watchdog на Lenovo при смене LHR пишет `~/.config/samostroy/public_api_url` и (если есть `GITHUB_TOKEN`) шлёт `repository_dispatch` → Action обновляет только `api-config.json` на `gh-pages`.
- На ASUS: `deploy/sync-api-config.ps1` читает URL по SSH и пушит тот же файл без rebuild.
- Named Cloudflare tunnel `samostroy` по-прежнему healthy, но без DNS-зоны стабильного hostname нет — рекомендуем домен + CNAME позже.

## Как пользоваться

После ротации туннеля подождите watchdog (до ~5 мин) или с ASUS: `pwsh deploy/sync-api-config.ps1`. Обновите вкладку CRM — API base подтянется из `api-config.json`.
