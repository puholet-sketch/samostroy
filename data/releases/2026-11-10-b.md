Публичный HTTPS к API восстановлен после очередного 502 на free `*.lhr.life`. Параллельно на домашнем Lenovo включён RDP только для LAN.

## Зачем

Hostname `e9b487d5ee305b.lhr.life` (релиз `2026-11-10-a`) начал отдавать **502**. API на Lenovo по LAN оставался живым — снова упал только туннель `samostroy-lhr`.

- Новый URL: `https://b1b66beb275a3a.lhr.life` (`/health` → 200)
- `.env.production`: `VITE_FEEDBACK_API_URL` обновлён; Pages пересобран

- На Lenovo: **xrdp** слушает `192.168.1.39:3389` (не интернет); вход пользователем `sa`, сессия XFCE

## Ограничения

- Free `*.lhr.life` снова сменится при рестарте `samostroy-lhr` — обновить `.env.production` и Pages.
- Для RDP из Windows: «Подключение к удалённому рабочему столу» → `192.168.1.39`. Если локальная сессия `sa` уже открыта на ноутбуке — сначала выйдите из неё (или закройте автологин-сессию), иначе вход по RDP может не открыть рабочий стол.

## Как пользоваться

1. CRM → Настройки → «API / уведомления» — Base URL = `https://b1b66beb275a3a.lhr.life` (или очистить override в localStorage)

3. RDP: см. раздел «Удалённый рабочий стол (xrdp)» в `docs/modules/lenovo-server.md`
