# 2026-11-22-c — LHR после watchdog

## Зачем

Watchdog на Lenovo поднял новый free LHR hostname; GitHub Pages ещё пекли `cc287da7947296.app.lhr.life` → 502 / Failed to fetch у формы прораба.

## Что сделано

- Подтверждён `/health` 200 на `https://1315e26a88aa83.app.lhr.life`.
- `.env.production`: `VITE_FEEDBACK_API_URL` → новый hostname; Pages пересобран.
- `BUILD_STAMP`: `2026-11-22 · lhr 1315e26a`.

## Ограничения

- Free `*.lhr.life` снова сменится при рестарте туннеля — тогда обновить `.env.production` и Pages.
- Override Base URL в localStorage CRM перекрывает URL из сборки.
- AdGuard DNS на домашнем Wi‑Fi может блокировать `*.lhr.life` — whitelist или публичный DNS / мобильный интернет.

## Как пользоваться

Отчёт прораба с телефона → «Отчёт сохранён в общую базу» при живом туннеле.
