# 2026-11-05-b — Домашний сервер Lenovo

Бэкенд СамоСтрой переехал на постоянный Ubuntu Server (Lenovo V15-IIL): Postgres + API в Docker, сон отключён, фронт остаётся лёгкой статикой на GitHub Pages.

## Зачем

Раньше API крутился на рабочем Windows-ПК и гас вместе с ним. Теперь база и REST живут на отдельной машине в LAN; телефоны и Pages ходят через Cloudflare Tunnel (HTTPS).

## Что внутри

- Compose: `postgres` (только localhost:5433) + `api` (:8787)
- Health: `/health` → postgres store
- Документация развёртывания: `docs/modules/lenovo-server.md`, скрипты `deploy/server/`
- Telegram-боты: слот в `.env` на сервере (токены подключить отдельно)

## Как пользоваться

1. Сервер: `docker compose up -d` в `/home/sa/samostroy`
2. Туннель: `systemctl --user status samostroy-tunnel`
3. В CRM → Безопасность → Замечания / API — Base URL = HTTPS туннеля, токен = `FEEDBACK_TOKEN` сервера
