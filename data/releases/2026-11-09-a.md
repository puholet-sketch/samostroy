# 2026-11-09-a — Скрыты замечания и FAB

Модуль «Замечания» убран из пользовательского контура CRM: ни владелец, ни другие роли больше не видят кнопку сбора отзывов и раздел инбокса.

## Зачем

Ранее из чекбоксов учёток убрали только «Замечания», но красная FAB справа и пункт меню оставались. Пользователи продолжали воспринимать это как рабочий сценарий. Нужно закрыть входные точки в UI, не ломая серверный API и ботов.

## Что внутри

- FAB и кнопка «Замечание» в сайдбаре отключены
- Пункт «Замечания» исчез из меню; маршрут `/feedback` закрыт правами
- Вкладка настроек переименована в «API / уведомления» — туда по-прежнему можно завести URL API и Web3Forms для дедлайнов и отчётов
- Код capture/inbox/API на диске остаётся, но в продукте его не показывают

## Как пользоваться

1. Войдите под любой ролью — справа нет красной круглой кнопки
2. В меню нет «Замечания»
3. Настройки → «API / уведомления» — только для владельца, если нужен туннель API
