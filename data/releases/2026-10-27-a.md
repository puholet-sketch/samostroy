# Pro-пакет: Amo, список клиентов, сводный отчёт и локальный API

Пакет для ежедневной работы менеджера и прораба плюс фундамент общей БД на своём ПК.

## Зачем бизнесу

- В карточке клиента ссылка на **AmoCRM** открывается одной кнопкой; чекбоксы «Доступ: Ремонт/Дизайн» убраны — клиентский кабинет ещё не в проде, галочки только путали.
- Список клиентов читается быстрее: **10 строк на страницу**, свежие сверху.
- На «Контроле объекта» — **сводный отчёт за период** по всем адресам: таблица в браузере, печать или «Сохранить как PDF». Удобно для планёрки и сверки «кто сдал дневной отчёт».

## Общие отчёты и Docker

Дневные отчёты прораба и ссылки контроля могут уходить в **Postgres через API** (`docker compose up -d` → `http://127.0.0.1:8787`). Так данные общие между браузерами на этом ПК.

**Важно:** сам GitHub Pages — только статика. С публичного сайта браузер **не достучится** до localhost API, пока нет туннеля (cloudflared и т.п.) или API на сервере. Без API всё по-прежнему в localStorage этого браузера; Web3Forms для замечаний на Pages работает как раньше.

## Как проверить

1. `/clients` — пагинация, новые сверху; карточка → «Ссылка на AmoCRM» → «Открыть».
2. `/control` → даты периода → «Сводный отчёт» / «Выгрузить» → печать.
3. Локально: `docker compose up -d`, в `.env` URL/токен API → сдать отчёт по ссылке прораба → он виден после обновления на другом профиле браузера.
4. Сборка в шапке замечаний / «Обновления»: `2026-10-27 · pro pack period a`.
