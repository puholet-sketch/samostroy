# 2026-11-06-b — API через localhost.run

Публичный HTTPS к API на Lenovo восстановлен после очередного падения Cloudflare quick tunnel.

## Зачем

Hostname `donald-kernel-vcr-cabinets.trycloudflare.com` (релиз `2026-11-06-a`) начал отдавать Cloudflare **530 / error 1033**. Рестарты `samostroy-quick` выдавали новые `*.trycloudflare.com`, но edge либо не резолвил туннель, либо отдавал один удачный `/health` и сразу снова 502/530. Named tunnel `samostroy` при этом остаётся подключённым к colo, но **без DNS-зоны** у него нет стабильного публичного URL для Pages.

## Что внутри

- Временный туннель: systemd user `samostroy-lhr` → `ssh -R 80:127.0.0.1:8787 nokey@localhost.run`
- `.env.production`: `VITE_FEEDBACK_API_URL` → `https://972658b8835506.lhr.life`
- `samostroy-quick` остановлен (trycloudflare нестабилен с этой сети)
- Пересборка GitHub Pages

## Ограничения

- Free `*.lhr.life` меняется при рестарте `samostroy-lhr` — снова обновить env и Pages.
- Долгосрочно: зона DNS в том же Cloudflare-аккаунте → CNAME на `ab87fe84-9ecf-4e30-9d72-239959d7eb3e.cfargotunnel.com`.

## Как пользоваться

1. CRM → Безопасность → Замечания / API — Base URL = текущий `*.lhr.life` (или очистить localStorage override)
2. На Lenovo: `systemctl --user status samostroy-lhr`
