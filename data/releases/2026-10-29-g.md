# GitHub Pages: обновление по прямой ссылке

Раньше обновление страницы на маршруте вроде `/control` или `/calculator` на GitHub Pages показывало стандартную ошибку «File not found»: сервер искал файл по пути и не находил его.

## Что изменилось

1. **SPA fallback.** При сборке с `GITHUB_PAGES=1` в `dist` копируется `index.html` → `404.html`. Pages отдаёт оболочку приложения для отсутствующих путей; React Router читает URL из адресной строки и открывает нужный экран.
2. **`.nojekyll`.** В артефакте сборки явно есть маркер без Jekyll-обработки статики.
3. **Прораб и остальной CRM** — без изменений логики; только деплой и доступность deep-link после refresh.

Маркер сборки: `2026-10-29 · spa 404 fallback g`.
