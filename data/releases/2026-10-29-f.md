# Прораб: отчёт в CRM, без лишних разделов

Прораб заполняет дневной отчёт по объекту **внутри CRM** (сайдбар, шапка, выход), а не на «отдельной публичной странице». Публичная ссылка для телефона без логина остаётся, но без кнопки входа в CRM.

## Что изменилось

1. **Форма в AppShell.** Маршрут `/control/report/:token?date=` — та же карточка отчёта, что была на публичной странице, но с навигацией «К контролю объекта». С календаря на `/control` день и «Форма →» ведут сюда.
2. **Публичная `/report/:token`.** Ссылка для шаринга сохранена; убрана «Вход в CRM». Если пользователь уже в сессии и имеет `object_control`, его переносит в shell-версию формы.
3. **Роль прораба.** По умолчанию только модуль `object_control` (без «Обновлений»). Старт после входа — `/control`. Пункты клиентов / калькулятора / договоров / замечаний / обновлений в меню не видны; прямой заход редиректит на домашний раздел. Сводный отчёт и «Пакет клиенту» для прораба скрыты (и по URL недоступны).
4. **Владелец** — полный набор модулей без изменений.

Маркер сборки: `2026-10-29 · foreman report shell f`.
