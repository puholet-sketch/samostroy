# Роль разработчика и durable-хранилище замечаний

Внутренние инструменты остаются **в том же CRM**: отдельного приложения для фиксов нет. Добавлена роль **Разработчик** — видит очередь замечаний и обновления, может копировать постановку, но не карточку клиентов с PII.

## Зачем бизнесу

- Передать доступ техническому специалисту без выдачи полного владельца.
- Клиент и прораб по-прежнему не видят внутренние настройки и брифы разработки.
- Замечания можно хранить не только в файле на телефоне, а в Postgres на ПК (Docker) — тот же адрес API в Безопасности.

## Как пользоваться

1. **Безопасность** — создать учётку с ролью «Разработчик» (демо: `developer` / `developer123`).
2. Войти → сразу **Замечания**; «Скопировать постановку» на карточке.
3. На ПК: `docker compose up -d`, в `.env` бота — `DATABASE_URL`, `npm start` в `bots/feedback-bot`.
4. В Безопасности указать Base URL API (`http://127.0.0.1:8787` локально или cloudflared для Pages).
