# Замечания с GitHub Pages на почту

На статическом хостинге у заказчика нет вашего Feedback API. Раньше замечание оставалось только в браузере клиента — разработчик его не видел. Теперь есть канал **email через Web3Forms**: браузер делает безопасный POST на публичный endpoint, письмо приходит на ящик команды.

## Зачем бизнесу

- Заказчик на демо Pages может слать замечания так же, как в полном контуре с API.
- Разработчик получает тему, описание, автора, страницу и метку сборки на почту (по умолчанию настроенный ящик).
- Скриншот по-прежнему хранится у заказчика локально; на бесплатном тарифе провайдера вложение часто недоступно — в письме будет пометка об этом.

## Как включить

1. Создать Access Key на [web3forms.com](https://web3forms.com) для нужного email.
2. Вписать ключ в `.env` (`VITE_WEB3FORMS_ACCESS_KEY`) перед деплоем **или** в CRM → Безопасность → «Feedback email».
3. При необходимости сменить «Кому» / `VITE_FEEDBACK_EMAIL_TO`.

Без ключа поведение прежнее: только локальное сохранение; UI честно пишет, что email не настроен.

## Для команды

Код: `src/lib/feedbackEmail.ts`, конфиг `feedbackConfig.ts`, submit в `feedbackApi.ts`. Документация: `docs/modules/feedback.md`, шаблон `.env.example`.
