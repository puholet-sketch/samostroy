# Страницы релизов в «Обновлениях»

Каждый релиз теперь можно открыть отдельной страницей: не только список коротких пунктов, а **бизнес-описание** новых возможностей и блок ссылок на **системную документацию** (архитектура, модули, API, поля, процессы).

## Зачем это бизнесу

- Понять, **что именно** появилось в CRM, без чтения кода.
- Быстро найти, **куда смотреть** в приложении (например инбокс замечаний) и какие файлы docs описывают устройство.
- Единый шаблон для следующих релизов: краткий changelog + страница с нарративом.

## Как пользоваться

1. Раздел **Обновления** — список релизов.
2. Клик по названию или «Подробнее» — страница релиза `/updates/<id>`.
3. Внизу страницы — ссылки на docs в репозитории и на разделы CRM.

## Для команды разработки

Паттерн описан в `docs/modules/updates.md` и в разделе «Обновления» архитектуры.
