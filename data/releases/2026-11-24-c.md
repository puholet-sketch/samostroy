# 2026-11-24-c — Карточка договора и смета без договора

## Зачем

Из реестра нельзя сразу «проваливаться» в мастер как в режим правки. Нужен просмотр атрибутов, повторная печать и отдельный путь: предварительная смета без ФИО с переносом в договор ремонта.

## Что сделано

- Клик по строке реестра открывает **модалку-карточку** (основные поля, клиент/объект/расчёт только для чтения).
- **Изменить** — полный мастер сущности с предзаполнением; **Скачать** — повтор PDF; **Перевыпустить** — только если после выпуска поля менялись.
- Плитка **«Выпустить смету (без договора)»**: свой счётчик `С-N`, адрес вручную, тот же калькулятор; на финише — **Перенести в договор** (только ремонт).
- Мебелировка по-прежнему **«скоро»**.

## Как пользоваться

1. **Договоры** → клик по строке → карточка → Скачать / Изменить / Закрыть.
2. Плитка сметы без договора → адрес → смета → выпуск → «Перенести в договор» → дозаполнить клиент/объект в мастере ремонта.
