# 2026-11-22-a — Мобильный Контроль: кнопки и октябрь

На телефоне в «Контроле объекта» кнопки отчётов выглядели «обрезками», а список клиентов «в работе» мог быть пустым — хотя на десктопе данные были.

## Зачем

Свежий GitHub Pages / новый браузер на телефоне поднимает публичный демо-сид. У карточек не было флага «объект в работе», поэтому Контроль показывал «0 / 0». Период по умолчанию — текущая неделя (в ноябре это 21–22.11), без сдвига назад октябрьские отчёты не выбирались.

## Что внутри

- Равная сетка кнопок на мобиле: сводный отчёт, пакет клиенту, сдвиг «← нед.» / «нед. →»
- Период Контроля пишется в `localStorage` и не сбрасывается при каждом открытии
- Демо-сид и залипший localStorage без `inWork` восстанавливают флаг для `demo-*` / source «демо»
- Тот же паттерн equal-height/width для фильтров Клиентов, футеров мастеров документов, сегментов калькулятора и кнопок в Настройках
- Календарь объекта по-прежнему: прошлый + текущий месяц (в ноябре — октябрь и ноябрь)

## Ограничения

- Реальные CRM-данные на телефоне по-прежнему только в localStorage этого браузера (без синхронизации с десктопом)
- Пакет клиенту использует период С→По с экрана Контроля (как сводный)

## Как пользоваться

1. Контроль → при пустом списке обновите страницу (миграция поднимет демо «в работе»)
2. «← нед.» несколько раз — до нужной октябрьской недели → «Сводный отчёт»
3. Выберите клиента → «Пакет клиенту»
