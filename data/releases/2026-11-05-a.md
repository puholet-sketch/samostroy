# Документы: guided-поток вместо вкладок

Раздел «Договоры и акты» больше не набор независимых вкладок: на входе хаб с плитками и пошаговые мастера до логического финиша (выпуск + скачивание + запись в реестр).

## Что умеет релиз

1. **Хаб** — дизайн, ремонт, акты, мебелировка (заглушка «скоро»), плюс реестры.
2. **Дизайн** — клиент → объект → тариф (2000 / 3900 / 4700 ₽/м²) с исключением пунктов 4.1.x / 4.4.x по тарифу; сквозной № договора; DOCX по структуре эталона.
3. **Ремонт** — смета (версии калькулятора), согласование, плановая дата старта, пакет: договор + смета + ТЗ-заглушка.
4. **Акты** — только из согласованных договоров ремонта; подмножество строк согласованной сметы; группировка по типу работ; № акта = этап 1…N.
5. **Реестр** и блок документов на карточке клиента → объект.

## Заглушки

- Мебелировка — плитка без бизнес-логики.
- ТЗ ремонта — placeholder до файла заказчика.
