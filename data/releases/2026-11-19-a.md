# 2026-11-19-a — Пакет по периоду, поиск клиентов, LHR

## Зачем

1. Форма прораба показывала «Сохранено локально (API: таймаут 15 с)» — Pages смотрел на мёртвый LHR hostname после ротации free localhost.run.
2. «Пакет клиенту» игнорировал период С/По на Контроле и всегда открывал текущую неделю сб→пт (ноябрь).
3. В списке клиентов / фильтре Контроля Enter в поле ФИО ничего не делал заметного — не было явного submit.

## Что сделано

- `openWeeklyPack` (панель + карточка объекта) передаёт `periodFrom`/`periodTo` в URL пакета; год календаря не подменяет период.
- Фильтры клиентов: `<form>` + кнопка «Найти», Enter применяет trim; live-фильтр по `onChange` сохранён; `matchClientFilters` ищет фамилию также в юр.лице / городе / менеджере / теге.
- POST отчёта: таймаут 25 с (было 15).
- Новый LHR: `https://225a6c9c893364.app.lhr.life` (`/health` → 200).
- `BUILD_STAMP`: `2026-11-19 · pack period + search + lhr`

## Ограничения

- Free `*.lhr.life` периодически меняет hostname — после рестарта туннеля снова нужен redeploy Pages.
- Если в Настройках CRM сохранён старый Base URL в localStorage, он перекрывает URL из сборки — сбросьте или обновите вручную.

## Как пользоваться

1. Контроль → выставить С/По (например октябрь) → выбрать клиента → «Пакет клиенту».
2. Клиенты / Контроль: печатаете фамилию — список сужается сразу; Enter или «Найти» тоже ок.
3. CRM → Настройки → API: Base URL = `https://225a6c9c893364.app.lhr.life` при локальном override.
